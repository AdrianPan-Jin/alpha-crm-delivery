Excel 多个表格合并：三种方法怎么选

三个办法，从「不用装软件」到「一次搞定 20 个文件」，按你的情况挑。

方法一：Power Query（推荐，Excel 自带、不写代码）

  1. 数据 → 获取数据 → 从文件 → 从文件夹，选中那批文件所在目录
  2. 点「合并并转换数据」→ 选工作表 → 确定
  3. 删掉不需要的列（保留「源」列名字方便追溯）→ 关闭并上载

优点：下次把新文件丢进同一目录，右键「刷新」就合并好了。
坑：表头必须一致；有空行会导致列错位。

方法二：直接追加（文件少、结构完全一致）

  1. 把第一个表放最上面，其余表依次贴在下面
  2. 删掉重复的表头行（选中 → 筛选 → 反选标题）
  3. 插一列「来源」，用 Ctrl+Enter 批量填文件名
  4. 数据 → 删除重复项（先按业务主键去重，别整行去重）

方法三：脚本（几十个文件、要定期跑）

用 Python + pandas 读目录下所有 xlsx，拼成一个表，顺手做类型清洗（金额去 ¥ 和逗号、日期统一格式），输出「合并表 + 汇总表 + 处理说明」。

判断标准：如果每周都要合一次，就别手动了。

合并后必须做的三件事

  • 核对总行数：合并后行数 = 各文件行数之和 − 表头数 ×（文件数−1）
  • 核对金额合计：合并前后总额一致，差一分都要查
  • 留一列来源：出问题时能定位到哪个文件、哪天导的
