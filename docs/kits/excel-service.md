# Excel 代做交付模板（clean.py）

把客户发来的乱表，30 分钟内做成可交付的成品：**清洗后 / 汇总（含图）/ 处理说明** 三个 sheet。

## 为什么有这个东西
闲鱼「Excel 代做」的交付物八成是同一套动作：去空格、统一日期、清理金额符号、去重、按两三个维度出汇总和一张图。
把它固化成脚本后，一单的实际工时从 1–2 小时压到 10–20 分钟，剩下的时间用在沟通和检查上。

## 用法
```bash
python clean.py 客户表.csv -o 交付.xlsx --title "销售数据清洗" --group 区域 --group 品类 --value 金额
python clean.py 客户表.xlsx -o 交付.xlsx --title "台账整理"          # 不给维度时只出清洗结果
```
- 输入：`.csv`（utf-8-sig / gb18030 自动回退）或 `.xlsx`
- `--group` 可重复，指定汇总维度；`--value` 指定求和列（省略则取第一个数值列）
- 输出三个 sheet：
  - **清洗后**：规范化的明细，冻结首行、标准表头
  - **汇总**：按维度透视求和 + 柱状图（前 20 行）
  - **处理说明**：逐条写清做了什么、影响了多少行（交付时直接给客户看，避免「你改了什么」的追问）

## 自动做的处理
| 处理 | 说明 |
| --- | --- |
| 删空行 | 整行为空直接删除，并记录行数 |
| 列名规范化 | 去换行、全角空格、连续空格；重名列自动加 `_2` |
| 文本清洗 | 去首尾空格、零宽字符、BOM |
| 数值识别 | `¥1,280.00`、` 1,050 `、`12%` → 数字（≥85% 可解析才当数值列） |
| 日期识别 | `2026-01-05`、`2026/10/18`、混排格式统一解析（≥85% 可解析才当日期列） |
| 去重 | 全文重复行删除并计数 |
| 汇总 + 图 | 按 `--group` 维度透视求和，生成柱状图 |

## 交付前的 3 条自检（人做的事，脚本不做）
1. 打开「处理说明」核一遍数字：读入行数 − 删除行数 = 输出行数
2. 抽查 3 行原始值 vs 清洗后，确认金额与日期没被「修」错
3. 汇总合计 ≈ 明细求和（脚本不自动校验，需人工点一次合计）

## 已验证
`samples/dirty-small.csv`（61 行，含前后空格、¥ 与千分位、两种日期格式、1 行全重复）→
输出 60 行 / 6 列 / 汇总 12 行 / 1 张图，处理说明记录 4 步。

```bash
python clean.py samples/dirty-small.csv -o samples/out-clean.xlsx --title "销售数据清洗" --group 区域 --group 品类 --value 金额（元）
```

# 自动化看板模板（dashboard.py）

把客户明细变成「数据 / 看板」两页，**全部用实时公式**：客户以后自己往下贴新行，按 F9 就刷新，不用重跑脚本。

```bash
python dashboard.py 销售明细.csv -o 看板.xlsx --title "2026 销售看板" \
    --date 下单日期 --amount 金额 --dim 区域
```

- **数据页**：原始明细（冻结首行、开筛选），客户自己维护
- **看板页**：
  - 4 个 KPI：总金额 / 订单数 / 客单价（`=IFERROR(B6/D6,0)`）/ 最大单笔
  - 月度趋势折线：`SUMIFS(金额, 日期, ">="&DATEVALUE("YYYY-MM-01"), 日期, "<="&EOMONTH(...,0))`，不依赖透视缓存
  - 维度 Top10 横向条形图
- 已验证：`samples/sales-240.csv`（240 行 × 12 个月）→ 总金额 1,151,805、订单 240、客单价 4,799.2、最大单笔 8,999，12 个月趋势与 4 个区域排行

## 交付话术（客户最关心的三点）
1. 「换数据即刷新」——不用每年找我重做
2. 「公式全开放」——每个格子都能点开看怎么算的，不是黑盒
3. 「附操作说明一页」——贴数据 → F9 → 截图汇报，三步
